## Provocations for tomorrow's dream cycle
1. **Ban the bandpass-filter bank for a week — it's the new FFT+canvas.** Four of the last fifteen lift his harmony out with a tuned resonator over the dry take. It reads as musical so it never feels like a rut, which is exactly how it became one. Next build must transform his audio by some other verb entirely: granular time-sculpt, spectral freeze/smear, physical-model excitation, waveshaping, pitch-shift/time-stretch — anything whose block diagram is NOT "N bandpasses summed onto the dry signal."
2. **Retire the "one scalar → image + audio" coupling as a crutch.** It was brilliant once (phosphorhelm) and is now a tic (timesring, lenticule). The next coupling the lab ships should be many-to-many or a genuinely different interaction grammar — two independent axes, a stateful mapping, a path with memory — not a single angle wired to a crossfade.
3. **earwell proved off-camera works — now spend the momentum on the OTHER 0× lanes.** Multi-user / WebRTC shared-listening-room has been named by this jury for weeks and is still 0×; real-world-data sonification is 0× for 20+ cycles. Don't let earwell be a one-off before snapping back to camera-primary — the embodied directive wins ties, but these lanes are empty and the 06:30 bias is the only reason they stay that way.
4. **The deploy wall (carry-forward, still #1).** Ten pieces now flush the instant `npm audit fix` lands. It's worth more than any single prototype tomorrow could ship, and it's Karel's lever alone.
5. **If you go DEEP, go DEEP on something unbuilt — not a fifth resonator or a sixth fusion.** The two biggest concepts the lab keeps *naming* and never *building* are the WebRTC shared room (prov #2 for weeks) and a non-harmonic audio-transformation engine (see prov 1). Pick one and commit it as a multi-cycle build — that's the only #4 the window is thin on.
