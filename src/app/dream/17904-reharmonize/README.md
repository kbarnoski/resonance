# Reharmonize

**Status**: demoable

What if you could play chords on your OWN recorded piano — re-harmonizing one of Karel's real takes into a live choir of itself? Reharmonize turns a single Welcome Home / Snowflake recording into a playable instrument: a touch, QWERTY, and Web-MIDI keyboard where every key you hold voices a transposed, sustained copy of his own take, so a C-E-G triad stacks three pitch-shifted versions of the same piano into a live choir of itself. This is the harmonize verb made literal — a re-voicing engine (transpose + stack), not grain-scrubbing. The audio engine is strict about the house rule that his real recorded catalog is the only sound source (never a synth, oscillator, or noise generator): on Begin the take is decoded once, a soft looping bed voice (playbackRate 1.0, low gain) plays continuously so the screen is alive before any key is touched, and each held key spawns a new looping `AudioBufferSourceNode` of the same buffer with `playbackRate = 2^(semitonesFromRoot / 12)` transposing within ±12 semitones. Each voice loops a musical window (~5 seconds of the take, never a sub-300ms grain) from a randomized start point so the stacked copies decorrelate into a real choir instead of a flanged unison; velocity maps to voice gain via `setTargetAtTime` attacks, note-off fades and stops, polyphony is capped at 8 with oldest-voice stealing, and a sustain toggle turns the keys into a held pad. A synthetic-impulse-response convolution reverb sits in as an effect (an IR is not a source), and every node terminates in the shared `createSafeMaster` bus — never `ctx.destination` — whose `AnalyserNode` drives the visuals. Mappings: on-screen keys and QWERTY (`z x c v b n m a s d g h j k l`, leaving f/i to the fullscreen/info HUD) play scale degrees of a selectable Major / Minor / Pentatonic scale; a plugged-in MIDI keyboard auto-connects through `navigator.requestMIDIAccess` and its noteon/noteoff messages (with velocity) drive the same engine chromatically. The visualization is warm-only (amber / gold / candle on near-black, with an absolute ban on violet / indigo / purple this cycle): each sounding voice is a warm beam placed on the x-axis by pitch-class, sized in height by pitch, and brightened by its live gain, over a slow breathing glow driven by the safe-master analyser, with held keys lit on the keyboard strip. Named references, deepened onto Karel's own recorded piano: the **Antares Harmony Engine** (a real-time multi-voice harmonizer) and the **Web Harmonium** (browser recording-as-instrument via real-time transposition + reed stacking); and arXiv 2604.23583 (2026, "Two Years of Performance with Intelligent Musical Instruments") for the instrument-as-relationship framing. Fallback behavior: the on-screen keyboard is always the primary, phone-friendly input and MIDI is never required (a mono status line reports `MIDI: <device> connected` vs `MIDI: none (tap the keys)`); if the audio decode fails, an on-brand `text-destructive` notice with a retry appears while the canvas keeps breathing, so the piece degrades gracefully and needs no WebGL.
