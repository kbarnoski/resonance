# 7480 — Einstein

## The one question

**What if a piece of music tiled the plane like the 2023 "einstein" aperiodic
monotile — ONE shape, laid down forever, that never once repeats — so the
melody it sounds can unfold endlessly and never loop back on itself?**

This is a cosmic-ambient / altered-states piece. The felt phenomenology is
*endless unfolding geometry that never returns to where it began* — the "it kept
opening into new rooms and never came back" quality of deep meditative space.
Drug-free: the screen and the sound do all the work.

## The technique (real, not faked)

The tiling is a genuine **aperiodic monotile tiling**, generated by
**substitution / inflation** — not by a random walk, not hand-placed.

It is a faithful TypeScript port of **Craig S. Kaplan's compact Spectre
substitution system** (<https://cs.uwaterloo.ca/~csk/spectre/>). Nine metatiles
— Γ (Gamma/"mystic"), Δ, Θ, Λ, Ξ, Π, Σ, Φ, Ψ — each carry a fixed rule that
replaces them with eight children under fixed affine transforms
(`buildSpectreBase()` → `buildSupertiles()` applied N times → `forEachTile()`
emits the final polygons). The emitted shape is the Spectre outline,
**Tile(1,1)**, a single equilateral 14-edge tile. At inflation **depth 3** from
a `Delta` supertile the system emits **559** copies of that one shape, in all
twelve orientations. This is provably the real aperiodic monotile: **no periodic
tiling of the plane by this shape is possible**, so the layout never repeats.

The whole port lives in `tiling.ts` (matrix helpers `mul` / `transPt` /
`transTo`, `buildSpectreBase`, `buildSupertiles`, and `buildTiling(depth)`).

### Honest freshness note

The monotile and its substitution math are the **2023 landmark result** of
Smith, Myers, Kaplan & Goodman-Strauss — I am **porting** it, not inventing it.
The compact substitution code is Kaplan's. The genuinely fresh *lab* move here
is the **sonification**: treating an aperiodic monotile as a **never-looping
melodic plane** and letting a playhead read pitch off each tile's orientation.

Note that the lab's existing **`837-quasicrystal`** is a **Penrose P3** tiling
(two rhombs, built from a de Bruijn pentagrid). **This is different**: a *single*
"einstein" tile — one shape, not two — generated by substitution rather than a
pentagrid dual.

## The audio mapping

Web Audio API; the AudioContext is created only **after the Begin gesture**.

- On **Begin**, a slow **playhead** traverses the tiling in the order the
  substitution produced the tiles (depth-first). A "sweep" mode re-orders the
  *visit* into a centroid spiral without changing the tiling.
- **Pitch = tile ORIENTATION.** Each Spectre sits in one of **twelve
  orientations** (30° steps). Orientation index `o` maps to a **just-intonation
  major-pentatonic** gamut: degree `PENTA[o mod 5]` (ratios 1/1, 9/8, 5/4, 3/2,
  5/3) times `2^floor(o/5)`, spanning ~two octaves. Because the tiling is
  aperiodic, the **stream of orientations never settles into a period** — so the
  melody is genuinely **non-looping**: neither random nor repeating.
- Each tile triggers one soft **FM voice** (sine carrier + gentle modulator + a
  quiet sub-octave), soft attack, long release, panned by tile x-position.
  The rare **Γ "mystic" pairs** get a brighter bell-like modulator ratio so they
  sparkle out of the texture.
- Space is kept low and reverberant: a small **algorithmic reverb** (four
  parallel feedback comb delays into a darkening lowpass) rather than a big busy
  mix. Cosmic, not busy.

## Long-form arc (evolves over minutes, never loops)

Over **~2.5 minutes** (`ARC_SECONDS = 150`) a single arc phase drives:

- **Harmonic rhythm slows** — tempo falls from 2.6 to ~1.05 tiles/sec.
- **Releases lengthen** and the modulation index eases off — the texture
  thickens and mellows.
- **Register sinks** — the pitch base drifts down almost an octave.
- A **fifth-drone** (A1–E2–A2) swells in from silence as a tonal bed.
- The **reverb opens** — wet level and feedback rise.

So **minute 3 sounds nothing like second 0**, yet nothing ever resolves or
repeats.

## Interaction & self-demo

- **Visuals autostart on load, silently** — a camera drifts and loosely follows
  the playhead through the plane. A silent reviewer with zero interaction still
  sees the piece unfold; after Begin they also hear it.
- **Begin** starts audio. **Click/tap** any region to fall into it (re-center +
  zoom). **Space** pauses. **Left/Right arrows** switch traversal order.

## How it degrades

- **No Web Audio** → the tiling still unfolds visually; a quiet notice appears.
- **`prefers-reduced-motion`** → camera drift, zoom-breathing and rotation are
  disabled (steady framing); the playhead still advances gently.
- **Non-GPU**: pure SVG (559 static `<path>` tiles rendered once; only a small
  playhead overlay pool and one camera transform update per frame) + Web Audio.
  No WebGL / WebGPU / three.js, no network, no server calls.
